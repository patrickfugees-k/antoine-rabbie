# Antoine & Rabbie — Invitation COSMIC LOVE

Invitation de mariage mobile-first.

## Contenu
- `index.html` : invitation complète
- `audio/amir-longtemps.mp3` : musique de l'invitation

## Déploiement GitHub Pages
1. Créer un dépôt GitHub.
2. Importer `index.html` et le dossier `audio`.
3. Activer GitHub Pages depuis les paramètres du dépôt.
4. Ouvrir le lien GitHub Pages sur téléphone.

## Musique
Le site tente de démarrer automatiquement la musique. Les navigateurs peuvent toutefois bloquer l'autoplay avec son. Dans ce cas, le premier toucher/clic de l'utilisateur lance automatiquement la musique.
